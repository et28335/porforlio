# 数字史学个人网页设计方案

**日期：** 2026-09-09  
**状态：** 用户已确认设计，待实施规划  
**网站定位：** 面向学术同行与合作机构的研究者档案与数字史学项目入口。

## 1. 目标与范围

网站首先回答“研究什么、怎样研究、何处进入成果”，而非按普通个人简历罗列经历。访问者应能在首页快速识别研究问题、当前议程、数字项目与可信的联系渠道。

首版包括研究者主页、研究、项目、成果、资料库、简介六个页面，以及中文主文和英文摘要。首版不包含用户注册、评论、站内全文检索、后台系统、未核验的档案原文或开放数据库承诺。

## 2. 受众与语言

- **核心受众：** 中国近现代史、数字人文及相关领域的学术同行、合作机构与项目伙伴。
- **次要受众：** 希望了解研究方向的学生与公众。
- **语言：** 中文为主；英文承担姓名、身份、项目名称和文章摘要的快速识别。首版不进行全文逐段对译。

## 3. 信息架构

### 3.1 首页

首屏使用“材料如何成为解释？”作为问题标题，辅以“档案—文本—证据”的轨道式图形。副标题说明研究在中国近现代史、史料保存、组织、验证与解释之间的关系。首屏只提供“进入研究议程”和“查看数字项目”两个主入口。

下一屏展示两项当前研究，随后以三张非对称项目卡展示：数字史学研究议程、跨国抗战档案平台、革命历史文件语料。页面末段用精简人物档案指向“简介”页。

### 3.2 研究

以三个可独立阅读的研究轴组织内容：

1. 中国近代政治史与革命史；
2. 档案、文本与历史证据；
3. 数字史学的材料边界与解释方法。

每一轴包括 80 至 150 字中文说明、英文摘要、代表成果链接与关联项目入口。

### 3.3 项目

每个项目独立成页，固定呈现项目目标、时间、材料范围、工作方法、当前状态、可访问成果、合作方式和推荐引用。项目状态只使用“公开可访问”“受限访问”“筹备中”三个标签。

### 3.4 成果

按“论文、章节、演讲、研究札记”筛选；默认按时间倒序。每条成果含完整书目信息、中文摘要、英文摘要、关键词、合法访问链接与引用信息。

### 3.5 资料库

只作为经过确认的项目与材料入口清单。每项说明材料来源、权利或访问条件、可引用方式与更新日期；不呈现无权限档案原图、无出处摘录或尚未确认的页码。

### 3.6 简介

参考 Harvard-Yenching Institute 人物页的清晰档案式组织：姓名中英对照、当前身份、研究领域、机构、在访时间、公开联系、CV 与 ORCID。正文分“学术经历定位”与“近期研究问题”两段；另设数字项目入口，不把页面做成纯履历表。

## 4. 视觉系统

- **视觉性格：** “档案感 × 数字研究室”，克制、编辑型而非企业科技风。
- **色彩：** 深海军蓝 `#081D2A` 为主背景；纸张暖灰 `#F2EFE7` 为阅读区；青绿 `#72D3CF` 为交互与方法线索；金色仅用于资料节点。
- **字体：** 标题使用高对比衬线字体（中文宋体/思源宋体，英文 Georgia）；正文使用无衬线字体。
- **版式：** 大尺度问题标题、宽留白、非对称网格、细分隔线。项目卡采用编号与状态，不使用轮播。
- **图形：** 轨道式档案—文本—证据关系图仅作身份标识；不把未经验证的数据做成可视化。
- **动效：** 仅使用链接悬停、页面进入及状态提示；禁止自动播放、视差堆砌和无意义滚动动画。

## 5. 内容模型与数据流

内容以 Markdown 或同等的版本化文本条目维护，由静态站点构建为页面。项目、成果和资料库共享下列字段：

`title_zh`、`title_en`、`type`、`year`、`summary_zh`、`summary_en`、`keywords`、`status`、`url`、`citation`、`source_or_rights`、`updated_at`。

发布流程为：核对原始材料与访问权限 → 填写结构化条目 → 构建静态页面 → 链接、移动端与可访问性检查 → 发布。任何可访问链接失效、版权变化或项目状态改变，均在条目层修订后重新构建。

## 6. 交互与边界

- 顶部导航固定提供“研究、项目、成果、资料库、简介、EN”。
- 项目卡与成果条目支持链接跳转；首版不加全文搜索和筛选器。
- “EN”只切换英文摘要/概要，不制造不完整的全站英语镜像。
- 对受限资源显示访问条件与目录链接，不把“可发现”写成“可在线获取”。
- 只有已确认可公开的邮箱、图像和外部链接才可上线。

## 7. 响应式、可访问性与质量

- 桌面端采用非对称双栏/三栏；移动端改为单栏，保留标题层级与项目顺序。
- 颜色对比度、键盘焦点、图片替代文字、语义标题层级与 PDF 链接说明均为验收项。
- 图像必须压缩并给出替代文字；正文不以图片承载关键学术信息。
- 发布前验证：所有导航和外链、下载文件、移动端 375px/768px/1440px 三档布局、中文与英文摘要、项目状态标签、资料版权说明和页面性能。

## 8. 技术边界

推荐使用静态站点架构与 Markdown 内容集合，保证快速、可移植、低维护，并适合学术材料的版本化校对。首版不使用数据库、登录、用户上传、评论或动态数据服务；这些功能只有在明确的维护责任与权限方案出现后才另行设计。

## 9. 验收标准

1. 首页可在 30 秒内明确研究问题、研究范围与项目入口；
2. 每项项目/成果可定位到相应说明、访问状态和引用信息；
3. 简介页完整呈现确认后的学术人物信息；
4. 任何资料库内容均有来源或权利说明，不暗示未经确认的开放访问；
5. 桌面与移动端无文字溢出、失效导航或不可操作的主要链接；
6. 视觉与已确认的“档案感 × 数字研究室”首页一致。
