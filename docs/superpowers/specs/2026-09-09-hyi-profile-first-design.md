# Harvard-Yenching 个人档案式首页改版设计

## 目标

将首页从“研究问题”开场调整为以 Harvard-Yenching Institute 个人资料为参照的学者档案式开场。访问者首先看见研究者身份、照片与经公开资料确认的个人简介；“项目”区紧接其后。

## 内容与顺序

1. **首屏个人档案**：Harvard-Yenching Institute 标识、中文与英文姓名、访问学者身份、研究领域、南开大学、在访时间、两段个人介绍、HYI 资料页链接，以及公开头像。
2. **项目**：保留既有三张项目卡片，成为首屏后的第一内容区。
3. **研究**：保留既有研究议程，置于项目之后。
4. **成果、资料库与页脚**：保留既有内容，顺次呈现。

## 资料边界

首屏文字只采用 Harvard-Yenching Institute 的公开个人页所明确提供的信息：访问学者身份、History 研究领域、南开大学、2026 年 8 月至 2027 年 5 月在访时间、北京大学历史学博士、耶鲁大学访学经历、中国近代政治史与数字史学研究方向，以及 1920 年代国民革命的近期研究。头像直接引用该页面的公开图片 URL；页面明确提供替代文字，不将该图像表述为本地或自有版权素材。

## 视觉与交互

- 延续现有深蓝、纸张色、青绿色和衬线标题的视觉系统。
- 桌面端首屏为文字资料与竖幅头像的两栏布局；移动端改为文字在上、头像在下。
- 主导航将“简介”作为首页锚点；“项目”置于首个内容区，其他链接保持可用。
- 项目、研究、成果和资料库的现有正文不作内容扩写或删改，只调整区段顺序与编号。

## 实现范围

- 修改 `site/index.html`：调整导航和区段顺序，替换首屏为个人档案，添加照片与来源链接。
- 修改 `site/assets/css/site.css`：为首屏资料、头像与响应式布局增加必要样式，并删除不再使用的轨道图样式。
- 修改现有页面结构测试：断言首屏资料、头像可访问性属性与“个人档案 → 项目 → 研究”的 DOM 顺序。

## 验证

1. 运行 Node 测试，确认结构、链接、图片替代文字与内容顺序。
2. 以本地静态服务分别检查桌面与移动宽度：照片不裁切主体、字段可读、导航和项目卡片不产生横向滚动。
3. 完成后由 GitHub Pages 工作流重新部署，并确认线上首页可访问。
